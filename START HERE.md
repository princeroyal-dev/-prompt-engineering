## 1. Prompt engineering kya hai, aur kyo padhna hai

Prompt engineering = AI ko aisa instruction dena ki pehli ya doosri koshish mein kaam ka output mile. Ye "magic words" ka khel **nahi** hai. Ye 3 cheezon ka khel hai:

1. **Clear thinking:** tumhe khud pata ho ki output kaisa chahiye.
2. **Right context:** AI ko wo information do jo sirf tumhare paas hai.
3. **Testing:** output check karo, prompt fix karo, repeat.

Purane tricks (jaise "tip dunga" ya "tum 100x expert ho") models ke saath ab bharosemand nahi hain. Fundamentals hamesha kaam karte hain, isliye ye course fundamentals par bana hai. Details: [[Mistakes and Fixes]].

## 4. Vault kaise kholo (Obsidian)

1. Zip ko extract karo.
2. Obsidian mein **Open folder as vault** choose karo, aur `Prompt-Engineering-Vault` folder select karo.
3. Diagrams Obsidian ke built-in Mermaid se render hote hain. `Learning Map.canvas` ke liye core plugin **Canvas** on hona chahiye (default mein on hota hai; nahi ho to Settings → Core plugins).
4. Graph View (left sidebar) khologe to saare notes ke connections dikhenge.

## 5. Seekhne ka tareeka (rule of the vault)

- **Padho → Karo → Log karo.** Sirf padhne se level up nahi hota. Har level ke exercises karo.
- Ek baar mein **ek cheez** badlo, phir output compare karo.
- Pass test ke checkboxes tick karne ke baad hi agle level par jao.
- Koi bhi AI chat (free plan bhi) exercises ke liye kaafi hai. API key zaruri nahi hai, jab tak Level 9–10 par tools/evals na karo.

> **Honest note:** Ye vault mera likha hua structured course hai, kisi official certificate wala nahi. Resource links ke liye [[GitHub Top Resources]] mein bataya hai ki kaunsa link maine khud khol kar check kiya aur kaunsa sirf lists se liya.

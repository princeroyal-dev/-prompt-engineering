# 🧪 Placement Test (15 min)

⬅️ [[10-Level Roadmap]]

**EN:** Run each task in any AI chat (free plan is fine). Score your *prompt* (not the AI's answer) using the checks. This is a rough self-assessment, not an exam.
**Hinglish:** Har task kisi bhi AI chat mein chalao. Score apne *prompt* ko do (AI ke answer ko nahi). Ye rough self-check hai.

---

## Tasks

### Task A: Study plan prompt
Write a prompt to get a 1-week plan to learn **C pointers**.
Score 1 point for each: (1) states your current level, (2) states time per day, (3) states the format of the plan, (4) states the goal (what you can do at the end).

### Task B: Fix a vague prompt
Rewrite: `Write about Docker.`
Score 1 point for each: (1) audience, (2) purpose, (3) length or scope limit, (4) output format.

### Task C: Format control
Ask the AI to compare two things (any two) in a **table with exactly 3 columns**.
Score 2 points if the table came out right on the first try, 1 if you needed one fix, 0 otherwise.

### Task D: Few-shot
Give 2 labelled examples (e.g., Hinglish sentences labelled positive/negative) and ask it to label a 3rd one.
Score 2 if you used a consistent example format and the AI followed it, 1 if partly, 0 if you never tried.

### Task E: Reasoning + verification
Give a multi-step word problem and ask the AI to show reasoning and then **check its own answer**.
Score 2 if you asked for both reasoning and a separate check, 1 for one of them, 0 for none.

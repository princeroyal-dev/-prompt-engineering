## How to use a template (5 steps)

1. Template copy karo.
2. `[BRACKETS]` ya `{{VARIABLES}}` ko apni details se bharo.
3. Chalao.
4. Output ko checklist se score karo (clear? correct? right format?).
5. Jo kaam kiya use [[My Progress]] ke Prompt Log mein save karo.

## Level ke hisaab se kya use karo

- **Level 1–2:** [[Anatomy and Master Template]], [[Cheat Sheet]], [[Mistakes and Fixes]]
- **Level 3–4:** [[Templates - Learning]] (flashcards, tutor), variables wale templates
- **Level 5–6:** [[Templates - Coding]] (debugging), grounded Q&A (Level 6 lesson)
- **Level 7+:** [[Templates - Meta]] aur chains

> **Rule:** Template andha copy karke mat chalao. Samjho ki har line kyu hai (Level lessons mein wajah di gayi hai), aur apne hisaab se badlo.

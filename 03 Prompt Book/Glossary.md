# 📖 Glossary (English + Hinglish)

⬅️ [[Prompt Book Index]]

| Term | Meaning (EN) | Hinglish |
|---|---|---|
| **LLM** | Large language model: AI trained on lots of text to generate text | Bada language model; text se train hua AI |
| **Token** | A piece of text (word or part of a word) the model reads/writes | Text ka chhota tukda jise model padhta/likhta hai |
| **Context window** | Max amount of text (in tokens) the model can handle at once | Ek baar mein model kitna text sambhal sakta hai |
| **Prompt** | Everything you give the model as input | Model ko diya gaya poora input |
| **System prompt** | Standing instructions for the whole conversation | Poori conversation ke liye hamesha ke rules |
| **User prompt** | Your request for this turn | Is baar ka tumhara request |
| **Zero-shot** | Instructions only, no examples | Sirf instruction, example nahi |
| **Few-shot** | Instructions plus a few examples | Instruction ke saath kuch examples |
| **Chain-of-thought** | Asking the model to write intermediate reasoning steps | Beech ke reasoning steps likhwana |
| **Reasoning model** | A model that reasons internally before answering | Jo answer se pehle andar reasoning karta hai |
| **Hallucination** | Fluent but wrong or invented output | Confident lekin galat ya banaya hua jawab |
| **Grounding** | Tying answers to provided source text | Jawab ko diye hue source se bandhna |
| **RAG** | Retrieve relevant documents and put them in the prompt | Relevant documents dhundh kar prompt mein daalna |
| **Temperature** | A setting for randomness (where available): lower = more predictable | Randomness ki setting; kam = zyada predictable |
| **Prompt chaining** | Splitting a task into steps; output of one feeds the next | Kaam ko steps mein todna |
| **Template / variable** | Reusable prompt with `{{placeholders}}` | Reusable prompt jisme bharne wale slots hote hain |
| **Delimiter / XML tag** | Markers like `<document>` separating parts of a prompt | Prompt ke hisse alag karne wale markers |
| **Eval** | A repeatable test of prompt quality | Prompt ki quality ka repeatable test |
| **Rubric** | Scoring criteria with levels | Scoring ke criteria |
| **LLM-as-judge** | Using an AI to score outputs | AI se outputs score karwana |
| **Regression** | Something that used to work breaks after a change | Pehle chalta tha, ab toot gaya |
| **Tool use / function calling** | Model asks your code to run a function and uses the result | Model code se function chalwata hai |
| **Agent** | A loop where the model plans, uses tools, observes, repeats | Plan → tool → observe ka loop |
| **Prompt injection** | Hidden instructions in outside text that try to hijack the model | Bahar ke text mein chhupe instructions |
| **Context engineering** | Designing everything that goes into the context (docs, tools, memory, history) | Context mein kya jaye, uska poora design |
| **Prefill** | Starting the model's reply yourself to steer format (support varies) | Model ka jawab khud shuru karna |
